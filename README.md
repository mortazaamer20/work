# نظام إدارة مجمع التأهيل والتعافي

نظام ويب متكامل (Django) لإدارة المستفيدين في مجمّع تأهيل وتعافي، مع تقييم يومي
لكل مستفيد عبر سبعة مراكز، وحساب **مؤشر التأهيل اليومي** تلقائياً، وتقارير
وإحصائيات قابلة للتصدير. الواجهة عربية بالكامل (اتجاه RTL).

---

## المزايا الرئيسية

- **نظام صلاحيات ديناميكي بالكامل**: أدوار تُنشأ من الواجهة مع تحكّم دقيق
  (مورد × إجراء) + عزل البيانات على مستوى المركز.
- **ملفات المستفيدين**: تسجيل المستفيدين وحالاتهم وبياناتهم.
- **التقييم اليومي الموحّد**: استمارة واحدة لكل مستفيد في اليوم، تشمل الأنشطة
  والعيادات لكل المراكز المتاحة. كل مستفيد له تقييمه المستقل (يدعم الجلسات
  الجماعية: عدة مستفيدين بنفس المركز، كلٌّ بتقييمه الخاص).
- **مؤشر التأهيل اليومي (0–100%)** محسوب من أربعة محاور موزونة:
  - الطبي والنفسي: **40%**
  - السلوكي والانضباطي: **20%**
  - المهاري والتقني: **20%**
  - الاجتماعي والروحي: **20%**
- **التقارير والإحصائيات**: على مستوى الفرد/المجموعة/المركز/الفترة الزمنية،
  مع تصدير **CSV** و **Excel**.
- **حقول تقييم مرنة**: لكل نشاط/عيادة حقول قابلة للإضافة من الواجهة
  (تقييم 1-5، 1-10، رقم، نص، اختيار، نعم/لا، تاريخ، وقت…).
- **الخصوصية والأمان**: حماية CSRF/XSS، أسرار عبر `.env`، أمان الجلسات،
  وحق حذف بيانات المستفيد.

## التشغيل المحلي (خطوة بخطوة)

### 1) تجهيز البيئة الافتراضية وتثبيت الحزم

**Windows (PowerShell):**
```powershell
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2) إعداد ملف البيئة `.env`

انسخ القالب وعدّل القيم:

```bash
cp .env.example .env      # على ويندوز: copy .env.example .env
```

محتوى `.env`:
```
DJANGO_SECRET_KEY=ضع-مفتاحاً-سرياً-قوياً-هنا
DJANGO_DEBUG=True
DJANGO_ALLOWED_HOSTS=*
DATA_RETENTION_DAYS=730
```
> في الإنتاج: اجعل `DJANGO_DEBUG=False` وحدّد `DJANGO_ALLOWED_HOSTS` بنطاقك الفعلي،
> وولّد `DJANGO_SECRET_KEY` جديداً وسرّياً.

### 3) قاعدة البيانات والبيانات الأولية

```bash
python manage.py migrate
python manage.py seed_data
```

أمر `seed_data` ينشئ: المراكز السبعة، الأنشطة/العيادات وحقولها، الأدوار
الافتراضية، ومستخدماً إدارياً.

### 4) تشغيل الخادم

```bash
python manage.py runserver
```

افتح: <http://127.0.0.1:8000/>

## ⚠️ ملاحظة مهمة عند التحديث

تم تحويل جميع الحقول الرقمية من `DecimalField` إلى `FloatField` (لحل تعارض
SQLite مع Python 3.12). إذا كانت عندك قاعدة بيانات قديمة، احذفها وأعد الإعداد:

**Windows:**
```powershell
del db.sqlite3
python manage.py migrate
python manage.py seed_data
```

**Linux / macOS:**
```bash
rm db.sqlite3
python manage.py migrate
python manage.py seed_data
```

## مؤشر التأهيل اليومي — كيف يُحسب؟

لكل تقييم يومي تُحسب درجة كل محور (0–100%) من سجلات الأنشطة والعيادات
وبيانات الاستمارة (الحضور، التفاعل، المزاج، المظهر)، ثم تُجمع الدرجات بأوزانها:

```
المؤشر = (الطبي×0.40) + (السلوكي×0.20) + (المهاري×0.20) + (الاجتماعي×0.20)
```

تصنيف النتيجة:
- **60% فأكثر** → تقدّم
- **40–59%** → ثابت
- **أقل من 40%** → تراجع يحتاج تدخّل
